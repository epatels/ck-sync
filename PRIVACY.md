# CK Sync: privacy policy

*Last updated: 5 November 2026*  
*Applies to CK Sync, all versions, from the setup program, winget or the Microsoft Store.*

**In short: CK Sync does not collect, send or sell any personal information. There are no accounts with us, no usage statistics and no tracking.**

## What stays on your PC
Your list of folder pairs, your settings, the log files and the backups of replaced or deleted files are stored on your PC only, in your
user profile (`%APPDATA%\CK Sync`) and in a hidden `.cksyncbackup` folder next to the files they belong to. The developer cannot see them.

## When CK Sync uses the internet
- **Cloud storage, only if you add a cloud account.** CK Sync then talks to the service you chose (for example Google Drive, OneDrive or
  Dropbox) to read and write the folders you picked in it. You sign in on that service's own web page; CK Sync never sees your password. The access
  token that the service gives back is stored encrypted on your PC. What that service does with your data is governed by its own privacy policy.
- **E-mail alerts, only if you switch them on.** CK Sync sends a short message about a failing pair through the mail server you enter yourself.
- **Updates.** The version installed with the setup program asks GitHub (github.com/epatels/ck-sync) whether a newer version has been released;
  nothing about you or your files is sent in that request (GitHub, like any web server, sees the address your PC connects from). The version
  from the Microsoft Store is updated by the Microsoft Store instead.

## What the developer receives
Nothing. CK Sync has no server of its own, no advertising, and no analytics.

## Data you put in an issue
If you write to the developer through GitHub Issues, what you post there is public and is handled by GitHub under
[GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
CK Sync itself never uploads logs or reports; you decide what to copy into an issue.

## Children
CK Sync is a general-purpose file tool and does not knowingly collect any information from anyone, including children.

## Changes
If this policy changes, the new text will be published at the same address and the date above will change.

## Contact
Open an issue at https://github.com/epatels/ck-sync/issues. Issues are public, so do not put personal information in them.
